Политика конфиденциальности

Настоящая политика определяет порядок обработки персональных данных при использовании сервиса Invella.

1. Оператор

Гаймана Екатерина Романовна, плательщик налога на профессиональный доход. Электронная почта для обращений: hello.invella@bk.ru.

2. Обрабатываемые данные

Сервис может обрабатывать адрес электронной почты пользователя, сведения о мероприятии и данные, которые пользователь самостоятельно вводит при создании приглашения.

При заполнении RSVP гости могут передавать имя, решение об участии, количество гостей и комментарий. Эти сведения доступны владельцу соответствующего приглашения.

3. Цели обработки

Данные используются для регистрации и работы аккаунта, сохранения и публикации приглашений, обработки ответов гостей, поддержки пользователей и исполнения договора.

4. Технические сервисы

Для работы Invella могут использоваться поставщики хостинга, базы данных, авторизации и платёжной обработки в объёме, необходимом для предоставления соответствующих функций.

5. Обращения

По вопросам обработки, уточнения или удаления персональных данных можно обратиться по адресу hello.invella@bk.ru.
