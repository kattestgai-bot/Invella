# Проверка Invella — 4 ноября 2026

## Изменения

- Новые операции ЮKassa возвращаются на `/payment-complete.html`. Благодарность, инструкция и оформление находятся в одном небольшом документе; редактор и SDK не нужны для показа инструкции.
- Страница использует существующий защищённый `/api/payment-status`. Только ответ сервера о подтверждённой оплате включает статус успеха. До пяти проверок за 20 секунд, повтор вручную, отдельные сообщения при отмене, ошибке и отсутствии сессии.
- Публичная ссылка показывается после подтверждения публикации и проверки формата slug. Идентификатор другого платежа в ответе не принимается. Параметры `paid=1` и `payment=success` не подтверждают оплату.
- Переход «Мои приглашения» открывает вход, затем кабинет. Сохранение скрытого редактора при входе с главной больше не планируется, что предотвращает создание пустого черновика.
- Завершение проверки одного платежа не удаляет новый платёж другой вкладки. Повторная проверка подтверждённого платежа доступна в той же вкладке в течение 24 часов только для того же владельца и всё равно запрашивает сервер.
- Событие аналитики отправляется после подтверждения сервером, один раз на устройство; в параметрах события только тариф.
